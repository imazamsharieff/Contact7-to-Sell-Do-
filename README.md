# Contact7-to-Sell-Do-Wordpress-plugin
A lightweight WordPress plugin that integrates Contact Form 7 (CF7) with Selldo CRM, allowing you to automatically send form submissions to your Selldo account as leads.

🚀 Features
Seamless integration between Contact Form 7 and Selldo CRM.
Sends form submission data directly to Selldo as a new lead.
Easy setup with API credentials.
Lightweight, no extra dependencies.

📦 Installation

Download the plugin files or clone the repository:
Upload the plugin folder to /wp-content/plugins/.
Activate CF7 Selldo Integration from the WordPress Plugins menu.
Make sure Contact Form 7 is installed and active.

⚙️ Configuration

Navigate to Settings → CF7 Selldo Integration in your WordPress dashboard.
Enter your Selldo API Key and SRD
Save settings and test by submitting a form.

📝 Usage
Create or edit a Contact Form 7 form.
Make sure your form includes these required field names:
[your-name]
[your-email]
[mobileno]
⚠️ These exact field names are required for the integration to work.
Submissions will automatically be sent to Selldo CRM as leads.
